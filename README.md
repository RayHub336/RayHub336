### 🚀 Proyectos B2B Destacados

**1. Sistema de Clasificación Automática NLP (B2B)**
*   **Contexto:** Procesamiento de un corpus de +47k registros para categorizar texto no estructurado, reduciendo el trabajo manual operativo.
*   **Solución:** Pipeline analítico con implementación rigurosa de control de calidad (*Evaluations*) y preparación para *Supervised Fine-Tuning* (SFT) usando embeddings.
*   **Resultados:** Modelo de producción con un F1-Score optimizado de 0.8734.
*   [🔗 Ver Repositorio](https://github.com/RayHub336/b2b-nlp-text-classification)

**2. Motor Predictivo de Churn B2B (API Rest)**
*   **Contexto:** Identificación temprana de riesgo de fuga de clientes corporativos para despliegue de campañas de retención.
*   **Solución:** Modelo de Machine Learning (LightGBM) empaquetado como un microservicio B2B utilizando FastAPI y Dockerizado para su integración de máquina a máquina (M2M) con sistemas ERP/CRM.
*   [🔗 Ver Repositorio](https://github.com/RayHub336/b2b-churn-prediction)

**3. NextWave AI — Bot de Trading Autónomo (AWS)**
*   **Contexto:** Operación en mercados de alta volatilidad sin supervisión humana 24/7.
*   **Solución:** Bot desarrollado en Python y desplegado en una instancia AWS EC2, utilizando Random Forest y Active Learning para reentrenamiento semanal.
