## 🚀 Proyectos Destacados

### 1. NextWave AI — Bot de Trading Autónomo (AWS)
**Contexto:**
El mercado de criptomonedas opera 24/7 y es altamente volátil. El objetivo fue crear un sistema que pudiera operar sin supervisión humana, gestionando el riesgo automáticamente.

**Solución Técnica:**
Desarrollé un bot en **Python** desplegado en una instancia **AWS EC2**.
* **Algoritmo:** Implementé un modelo *Random Forest* para clasificar oportunidades de entrada.
* **Active Learning:** El sistema evalúa sus propias operaciones y se re-entrena semanalmente para adaptarse a cambios del mercado.
* **Automatización:** Uso de Cron Jobs para ejecución continua y notificaciones en tiempo real vía Telegram.

**Resultados:**
* Operación ininterrumpida 24/7.
* Reducción de falsos positivos mediante el umbral de confianza del modelo de ML.

**Resultados:**
* Creación exitosa de una base de conocimientos consultable que reduce el tiempo de investigación manual.
