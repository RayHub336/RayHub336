## 🚀 Proyectos Destacados

### 1. NextWave AI — Bot de Trading Autónomo (AWS)
**Contexto:**
El mercado de criptomonedas opera 24/7 y es altamente volátil. El objetivo fue crear un sistema que pudiera operar sin supervisión humana, gestionando el riesgo automáticamente.

**Solución Técnica:**
Desarrollé un bot en **Python** desplegado en una instancia **AWS EC2**.
* **Algoritmo:** Implementé un modelo *Random Forest* para clasificar oportunidades de entrada.
* **Active Learning:** El sistema evalúa sus propias operaciones y se re-entrena semanalmente para adaptarse a cambios del mercado.
* **Automatización:** Uso de Cron Jobs para ejecución continua y notificaciones en tiempo real vía Telegram.

**Resultados:**
* Operación ininterrumpida 24/7.
* Reducción de falsos positivos mediante el umbral de confianza del modelo de ML.

### 2. Interactive Vehicles Dashboard — Exploratory Data Analysis (EDA)
**Contexto:**
Desarrollo de una aplicación web interactiva para explorar y analizar un conjunto de datos de anuncios de venta de vehículos en Estados Unidos, con el fin de encontrar patrones de precios.

**Solución Técnica:**
* Limpieza y preparación de datos (manejo de valores nulos y atípicos) usando **Pandas**.
* Creación de visualizaciones interactivas (histogramas y diagramas de dispersión) utilizando **Plotly Express**.
* Construcción y despliegue de la interfaz de usuario mediante **Streamlit**.

**Resultados:**
* Un dashboard funcional y amigable que permite a usuarios no técnicos filtrar y explorar visualmente las métricas clave del mercado de autos usados.

🔗 [Ver Repositorio](https://github.com/RayHub336/Sprint-7---vehicles_dashboard)
